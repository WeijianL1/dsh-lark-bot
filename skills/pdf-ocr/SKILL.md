# PDF 阅读

如果附件消息已经提供 `document.md` 和 `report.json`，先读取这些结果，不重新跑 OCR。
对于历史文件或尚未解析的本地 PDF，使用本技能目录下的脚本：

```bash
python3 scripts/pdf_smart_parse.py "文件.pdf" --output "提取文本.md"
```

`pdf_ocr.py` 是同一个兼容入口。可用 `--pages "1-5,8,10-"` 明确限制页码；默认处理全文。优先使用 `--output` 避免将全文塞进工具输出。

引擎自动逐页处理、保存断点和高清重试。不要自行用 xargs、并行 shell 或多个批次拆分同一文档；只启动一次，等待或查询该进程状态。中断后重跑相同命令会复用已完成页面，旧脚本产出的纯文本不是可验证断点。

在飞书会话的 shell 中，脚本利用 `DSH_SESSION_ID` 自动交给本地 bot，引擎在原会话显示独立进度条卡片。无需手写进度消息或传 chat ID。`/stop` 可暂停。非飞书会话用同一引擎本地运行；桥接不可用时明确报错，`--local` 可显式选择不发送卡片。

完成后查看返回的复核清单，向用户说明仍不清楚/失败的原始页码；识别置信度不等于内容准确率。部分页码结果不能宣称已读全文。原始 PDF 不变；150 DPI 灰度压缩识别，模糊区域 300 DPI 重试。旧 `--dpi` / `--force-ocr` 参数仍可解析，但统一引擎固定使用上述策略。`--classify-only` 仅返回页数元信息，不宣称已完成识别。
